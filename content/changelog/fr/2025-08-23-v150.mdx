## Nouveautes

Cette version introduit un systeme complet de feedback admin et des ameliorations de documentation.

### Fonctionnalites

- Composant **GridBackground** pour un design visuel personnalisable
- **Systeme de feedback admin** avec filtres, tableaux et vues detaillees
- **Systeme de documentation** avec contenu dynamique et navigation par sidebar
- **Suivi du dernier provider utilise** pour ameliorer la connexion
- **Pages contact et a propos**

### Maintenance

- Mise a jour de Next.js vers 15.5.0
- Mise a jour de React vers 19.1.1
- Mise a jour de l'AI SDK vers v5
- Mise a jour de tous les packages de composants Radix UI
- Mise a jour des dependances de test et des outils de build
- Integration Claude Code avec nouveaux agents, commandes et hooks de formatage
- Amelioration de l'organisation des fichiers API et de la structure de documentation
